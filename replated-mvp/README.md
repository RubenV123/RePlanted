# RePlated MVP demo

Open index.html in a current browser. No install is needed. The prototype stores synthetic data in browser local storage; reset from the top bar.

## Flow

Donor submits unserved surplus, portions, preparation time, measured temperature, known allergens, pickup deadline and packaging confirmation. Dispatcher performs a human review, then offers an eligible listing to an NGO. The NGO confirms or declines capacity. Only after confirmation can dispatch assign a rider. Rider records pickup, route start and recipient handoff. Activity is visible in the audit trail.

## Boundaries

This is not a live food service. No backend, login, live maps/GPS, notification, payment, identity check, FSSAI verification or server jobs exist. Checklist fields do not prove food is safe. A real pilot requires a trained accountable operator, validated handling and temperature processes, packaging and transport, recipient capacity, incident procedures, legal review and applicable FSSAI compliance. Demo records are local and synthetic.

The prototype chooses dispatcher-assigned riders over an open gig marketplace: for an initial local pilot, known riders after recipient confirmation are easier to supervise and give a more credible chain of custody.
